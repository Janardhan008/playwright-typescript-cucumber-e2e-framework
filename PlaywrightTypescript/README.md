# Playwright + TypeScript + Cucumber E2E Framework

## 📌 Overview
This project is an **end-to-end automation framework** built with **Playwright**, **TypeScript**, and **Cucumber (BDD)**.  
It enables cross-browser testing (Chromium, Firefox, WebKit) with business-readable test scenarios written in **Gherkin syntax** (`Given/When/Then`).  

The framework is designed for **scalability, maintainability, and CI/CD integration**, making it suitable for modern QA workflows.

---

## ✨ Features
- ✅ **Playwright** for fast, reliable browser automation  
- ✅ **TypeScript** for type safety and clean code structure  
- ✅ **Cucumber (BDD)** for business-readable test scenarios  
- ✅ **Cross-browser support** (Chromium, Firefox, WebKit)  
- ✅ **Reusable step definitions** for modular test design  
- ✅ **HTML/JSON reporting** for test results  
- ✅ **CI/CD ready** with Jenkins/GitHub Actions integration
